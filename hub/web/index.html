接入原应用通知

接入说明 →

在 Codex、Claude Code 或 Cursor 原应用里运行的任务，也可接入飞书通知。选择程序后，点击下方按钮安装事件通知。

Cursor 默认只通知完成；开启逐条审批后，每条 Shell 命令都会等待你的允许。Codex 和 Claude Code 的权限请求可在飞书回应。

Codex 安装后需要在原应用打开 /hooks，核对并信任新增的通知；程序不会自动替你信任。
